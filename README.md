# Atlas Forge

**Atlas Forge** is a fictional one-page website for a modern strength-training gym in Shenzhen.

I designed and developed this project as part of my front-end development portfolio. My goal was to create a professional gym website with a strong visual identity, clear calls to action, responsive layouts, and an easy booking experience.

## About the Developer

My name is **Zakaria Laouibi**. I have a background in web and mobile development, and I created Atlas Forge to demonstrate my ability to design and build modern business websites using Vue.

For this project, I worked on:

- The website concept and visual direction
- The page structure and user experience
- The responsive desktop and mobile layouts
- The Vue components and reusable data
- The navigation and interactive buttons
- The membership, program, coach, location, and contact sections
- The booking form and validation
- The final styling, accessibility, and performance improvements

## Project Overview

Atlas Forge is designed as a realistic website concept for a strength-training studio. It uses a dark industrial style, bold typography, structured content, and clear conversion-focused sections.

Although the business itself is fictional, the website was built to represent the quality and structure I could deliver for a real freelance client such as a gym, coach, fitness studio, restaurant, or local business.

## Main Features

- Sticky desktop navigation with working section links
- Accessible mobile hamburger menu
- Full-screen hero section with functional call-to-action buttons
- Program cards generated from Vue data
- Membership pricing cards with a highlighted recommended plan
- Coach profile section
- Testimonial section
- Shenzhen location section with an embedded map
- Reactive booking form with required-field and email validation
- Responsive footer with a dynamic current year
- Visible keyboard focus states
- Reduced-motion support
- Responsive design for mobile, tablet, laptop, and desktop screens

## Technology Stack

- Vue 3

- JavaScript

- CSS
- OpenStreetMap embed
- Open Graph and SEO metadata

## Installation

Install the project dependencies:

```bash
npm install
```

## Run Locally

Start the development server:

```bash
npm run dev
```

Then open the local address displayed in the terminal.

## Build for Production

Create a production build:

```bash
npm run build
```
